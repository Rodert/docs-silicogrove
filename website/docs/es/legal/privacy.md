# Politica de privacidad

SilicoGrove respeta la privacidad y procesa la informacion de acuerdo con las leyes aplicables.

- La informacion se utiliza solo cuando es necesaria para operar, proteger, dar soporte y mejorar los servicios.
- Aplicamos medidas razonables para prevenir el acceso, uso o divulgacion no autorizados.
- Publicaremos actualizaciones en esta pagina cuando cambien nuestras practicas o los requisitos legales.

Este aviso breve se ampliara con la politica de privacidad completa.
