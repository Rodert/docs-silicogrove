# Частые вопросы

## Как получить API Key?

Создайте ключ в консоли SilicoGrove и храните его только на сервере. Передавайте его как `Authorization: Bearer YOUR_API_KEY`.

## Как проверить доступные модели?

Вызовите `GET https://ai.silicogrove.com/v1/models` с тем же ключом.

## Как обрабатывать видео-задачи?

Генерация видео асинхронна. Сохраните `task_id`, проверяйте задачу до завершения и скачайте видео через `/content`.

Другие ответы доступны в[английском FAQ](/faq/).
