# API

SilicoGrove API поддерживает текст, изображения, видео и аудио. Доступные модели и права определяются ответом `GET /v1/models`.

Для генерации видео используйте `POST /v1/videos`. В текущем рабочем примере используется `kling-video-v3`; сохраните возвращённый `task_id` и проверяйте состояние задачи.

Полные endpoint, поля запросов и примеры cURL доступны в[английской документации API](/api/).
